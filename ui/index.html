Atlas sur votre téléphone

  1. Activez Tailscale sur le téléphone.
  2. Scannez ce code avec l'appareil photo.
  3. Dans Safari : Partager, puis « Sur l'écran d'accueil ».

Ce code donne accès à Atlas. Ne le montrez à personne.

Adresse du téléphone non réglée. Lancez « tailscale serve --bg 8765 », puis mettez l'adresse https affichée dans config.json, champ url_telephone, et relancez Atlas.
